# RxDesk: Prescription Acceleration System

Target:
Hospital OPD Endocrinologist

Problem:
Prescription creation takes ~270 seconds.

Breakdown:
Diagnosis: 20 sec
Medicines: 130 sec
Tests: 50 sec
Advice: 50 sec
Followup: 20 sec

Goal:
Reduce prescription creation time below 60 seconds.

Features:
- Patient Management
- Prescription Management
- Favorite Medicines
- Favorite Tests
- Advice Templates
- Followup Templates
- Clone Prescription
- Print Prescription

Out of Scope:
- AI
- Billing
- Appointments
- Inventory
- Multi Doctor
- Authentication
